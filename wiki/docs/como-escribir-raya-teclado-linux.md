# ¿Cómo escribir la raya (guion largo) con el teclado en Linux?

Para escribir la raya se emplea la combinación de teclas `Ctrl + Shift + U`, se suelta la combinación y enseguida se presiona las siguiente secuencia con el teclado númerico: `2`, `0`, `1` y `4`. Por último, se presiona `Enter`.

> [!NOTE]
> Se emplea la combinación de teclas `Ctrl + Shift + U`, `2014` y `Enter`.
