# Sistema de notas basado en Markdown

Este repositorio me funciona como un almacén personal de notas en formato **Markdown**, pensado para centralizar documentación, apuntes de estudio, referencias técnicas y otros tipos de textos personales.

Está organizado para ser usado con [Obsidian](https://obsidian.md/) o cualquier editor Markdown compatible, y está estructurado por temas y categorías para facilitar la consulta y la expansión continua del conocimiento.

## Propósito

La misión de esta bóveda es:

- Guardar apuntes de cursos y aprendizaje continuo.
- Conservar documentación técnica útil.
- Mantener notas personales y reflexivas.
- Documentar procesos, comandos y configuraciones relevantes.
- Crear un espacio de consulta rápida y ordenada.
